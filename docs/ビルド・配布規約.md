# utter ビルド・配布規約

Xcode / Swift Package Manager / GitHub Actions / GitHub Releases によるビルド・署名・配布の規約。
要件の根拠は [要件定義.md](要件定義.md) の3章・12.6節。

---

## 開発環境

| 項目 | 前提 |
|---|---|
| Mac | Apple Silicon |
| macOS | 26 以降（SpeechAnalyzer を使うため） |
| Xcode | 26 以降（Swift 6） |
| 依存管理 | Swift Package Manager のみ。CocoaPods / Carthage は使わない |
| 補助ツール | shellcheck（`brew install shellcheck`）、gh |

---

## 依存関係

- 依存は各 Package の `Package.swift` に記述し、`Package.resolved` をコミットしてバージョンを固定する
- 依存を追加する前にライセンスを確認する（Apache-2.0 と両立するもの）。モデル重みのライセンスも別途確認する。確認結果は [ライセンス・依存関係.md](ライセンス・依存関係.md) に出典と確認日つきで記録する
- 依存の更新は Dependabot（`swift` エコシステム）が PR を作成する。自動マージはせず、人がレビューしてマージする

## 署名と識別子

Accessibility 等の権限はコード署名に紐づくため、署名が変わると再許可が必要になる。

- Team ID・Bundle ID・App Group ID はリポジトリに固定せず、`Local.xcconfig`（gitignore 済み）で上書きする。雛形として `Config/Local.xcconfig.example` を用意する（ターゲット作成時）
- 自前ビルド利用者向けに、固定の開発用署名でビルドする手順を README に記載する。Ad Hoc 署名は再ビルドのたびに権限が外れるため使わない（方式案は [ライセンス・依存関係.md](ライセンス・依存関係.md) 4章）
- macOS 公式バイナリは Developer ID 署名＋公証。App Sandbox は原則使わない（他アプリへの AX 操作のため）
- iOS は iOS Development 署名で本人端末にインストールする。無料 Personal Team は約7日で失効するため再インストールが必要。App Group が無料署名で使えるかは Phase i0 で検証する
- 証明書・プロビジョニングプロファイル・API キーはコミットしない。CI で署名が必要になったら GitHub Actions secrets を使い、PR からのワークフローに渡さない

## CI

`.github/workflows/ci.yml`

| job | ランナー | 内容 |
|---|---|---|
| 検証（`verify`） | `macos-26` | `scripts/verify.sh`（swift format lint、Package の build/test、shellcheck） |
| CI ステータス確認（`ci-status`） | `ubuntu-latest` | `verify` の結果を集約。branch protection の required check にする |
| カバレッジ計測（`coverage.yml`） | `macos-26` | `scripts/coverage.sh` の lcov を Codecov にアップロード。required check にはしない |

- アプリターゲットを作成したら、`scripts/verify.sh` に `xcodebuild build` / `test`（署名なし: `CODE_SIGN_IDENTITY=- CODE_SIGNING_ALLOWED=NO`）を追加する
- 実機・権限ダイアログ・マイクが必要なテストは CI で実行しない。手順書と記録で担保する
- Codecov のアップロードトークンは Actions secrets の `CODECOV_TOKEN` に設定する。アップロード失敗では CI を落とさない
- ランナーの macOS / Xcode バージョンを変えたときは、ローカルとの差異を README に記録する

## 配布

| 対象 | 方法 | フェーズ |
|---|---|---|
| macOS 公式バイナリ | GitHub Releases（Developer ID 署名・公証済み） | Phase 3 |
| macOS 自前ビルド | README の手順で Xcode からビルド | Phase 3 |
| macOS 自動更新 | Sparkle 2（更新確認は低頻度・無効化可能） | 後続 |
| iOS | Xcode から本人端末へ実機インストール | Phase i3 |

- STT モデルはバイナリに同梱せず、初回にユーザー操作で取得する（取得元・サイズを明示し、取得後に完全性を検証, PERM-03）
- リリースごとに性能・精度の計測結果を記録し、目標未達の項目は既知の制限として公開する（AC-19）
