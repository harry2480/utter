# 既知の制限

現在の main で、使えない・既定で無効・未確認の項目をまとめる（AC-19）。
Phase 0 / i0 の判定（要件定義 11章・14章）が出るまで方式を決めない項目は、判定待ちの Issue を併記する。
リリースの下書きの本文には、この一覧と計測結果（下の「計測結果の記録」）を書く（[ビルド・配布規約](ビルド・配布規約.md)「リリース」）。

項目を足したり外したりするときは、同じ PR でこの文書も直す。

## macOS

| 項目 | 現状 | 判定・作業の Issue |
|---|---|---|
| 音声認識のエンジン | 既定のエンジンを選んでいないため、Release ビルドではショートカットを押してもマイクを開かず、「音声認識が設定されていません」と表示する（文字入力には使えない）。Debug ビルドに限り、起動引数 `-UtterDebugSTTEngine speechAnalyzer` で SpeechAnalyzer を選べる | #48（SpeechAnalyzer）/ #49（WhisperKit） |
| WhisperKit | アダプターは先行実装のみで既定で無効。アプリと STT Worker にはリンクしていない | #49 |
| 修飾キー単独のショートカット・Esc でのキャンセル | 実装済みだが既定で無効。通常のキーの組み合わせのショートカットだけを使う | #51 |
| 挿入経路ごとの権限 | 経路ごとに要る権限が未確定のため、権限のオンボーディングでは「未定」として示し、要求しない | #41 |
| 挿入の互換性 | アプリ別の挿入経路・Undo の可否は未計測（[挿入互換性表](挿入互換性表.md)は書式のみ） | #41 / #59 |
| ChatGPT での整形 | Sign in with ChatGPT は未対応。OpenAI API キー方式の整形は先行実装のみで、アプリからは使わない | #50 / #58 |
| Edit Mode・Realtime Direct | Debug ビルドのメニューから確かめられるだけで、録音のセッションには結線していない（Edit Mode は `UtterEditModeEnabled` を設定したときだけメニューに出る） | #60 |
| クラウド STT | OpenAI 音声認識 API のアダプターは先行実装のみ。音声送信の同意画面と結線は未実装 | #60 |
| 自動更新（Sparkle） | appcast の URL と公開鍵をビルド設定で与えたときだけ動く。与えなければ Sparkle を起動しない | — |
| 公式バイナリ | Developer ID 署名・公証のワークフローはあるが、まだ配布していない。今は自前ビルドのみ | #47 / #59 |
| 速度・メモリ・電力 | 6章の目標は未計測。モデル保持モードは保存されるが、計測に基づく調整はしていない | #52 / #59 |
