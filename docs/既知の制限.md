# 既知の制限

現在の main で、使えない・既定で無効・未確認の項目をまとめる（AC-19）。
Phase 0 / i0 の判定（要件定義 11章・14章）が出るまで方式を決めない項目は、判定待ちの Issue を併記する。
リリースの下書きの本文には、この一覧と計測結果（下の「計測結果の記録」）を書く（[ビルド・配布規約](ビルド・配布規約.md)「リリース」）。

項目を足したり外したりするときは、同じ PR でこの文書も直す。

## macOS

| 項目 | 現状 | 判定・作業の Issue |
|---|---|---|
| 音声認識のエンジン | 既定のエンジンを選んでいないため、そのままビルドするとショートカットを押してもマイクを開かず、「音声認識が設定されていません」と表示する（文字入力には使えない）。自前ビルドでは `Config/Local.xcconfig` の `UTTER_MAC_STT_ENGINE = speechAnalyzer` で SpeechAnalyzer を選べる（Release でも。モデルは設定画面の「認識モデルと省電力」タブで取得する）。Debug ビルドでは起動引数 `-UtterDebugSTTEngine` でも選べる。WhisperKit は STT Worker に未登録のため選べない | #48（SpeechAnalyzer）/ #49（WhisperKit） |
| WhisperKit | アダプターは先行実装のみで既定で無効。アプリと STT Worker にはリンクしていない | #49 |
| 録音ショートカットの既定値 | 既定のショートカットがないため、設定画面の「録音とショートカット」タブで割り当てて保存するまで何も登録しない（メニューには「ショートカット: 未設定」と出る）。割り当てられるのは Command・Option・Control のいずれかを含む組み合わせと F1〜F20 で、修飾キー単独・Fn を含む組み合わせは記録できない（#51）。他アプリが独自に処理するショートカットとの重なりは検出できない | — |
| 初回セットアップ | 起動時に、最後まで進めていなければ「マイク → アクセシビリティ → 認識モデル → ショートカット → 整形の実行先」の手順を続きから開く。認識モデルの手順は Apple の音声認識（SpeechAnalyzer）だけに対応し、エンジンが未設定なら未設定であることを示して進める。モデルのサイズは macOS が管理するため取得の前には表示できず、取得後の完全性の確認も macOS に任せる（utter は照合しない）。どの手順も「あとで」で飛ばせ（権限も設定も変えない）、一度最後まで進めたら起動時には開かない。飛ばした手順はメニューの「初回セットアップ…」から続きを済ませる。権限のダイアログを含む動作は実機で未確認 | #198 / #48 / #49 |
| 修飾キー単独のショートカット・Esc でのキャンセル | 実装済みだが既定で無効。通常のキーの組み合わせのショートカットだけを使う | #51 |
| 挿入経路ごとの権限 | 入力欄への直接挿入（AX）に要るアクセシビリティは初回セットアップで求める。貼り付け・キー入力の経路は要る権限が未確定のため、初回セットアップでは「確認中」として示し、要求しない | #41 |
| 挿入の互換性 | アプリ別の挿入経路・Undo の可否は未計測（[挿入互換性表](挿入互換性表.md)は書式のみ） | #41 / #59 |
| Web サイト単位のスタイル | 既定で無効。設定画面で許可し、サイト別の上書きを足したときだけ、Accessibility で前面のブラウザのホスト名を読む（Accessibility の権限が必要）。Chromium 系のブラウザは Web 領域を公開しないことがあり、そのときはアプリ別のスタイルになる。ブラウザごとの読み取りは実機で未確認 | — |
| ChatGPT での整形（Sign in with ChatGPT） | 既定は無効（処理系は Local Basic）。設定画面の「整形の実行先と費用」タブで「ChatGPT（Sign in with ChatGPT）」を選び、「Continue with ChatGPT」でサインインし、モデルを選び、同意の画面で ChatGPT への整形の送信に同意したときだけ、利用者の ChatGPT プランで整形する。1つのアカウントだけを扱う（アカウントの切り替えはない）。ID トークンの署名の検証・ループバックの待ち受け・トークンの更新は実機で未確認。トークンエンドポイントのエラー本文の形などは出典にないため仮置き（[Phase0検証-ChatGPT登録条件.md](Phase0検証-ChatGPT登録条件.md)「付記: Sign in with ChatGPT の実装」）。利用条件（S13〜S15）の原文はリリース前に人が確認する。無料で利用者の端末上でのみ動く間に限る | #50 |
| クラウド整形の失敗時の切り替え | 既定は無効。「整形の実行先と費用」タブで選んだときだけ、Claude と Sign in with ChatGPT の一方が失敗したら、もう一方へ1回だけ送り直す（切り替え先への同意と条件がそろったときだけ, AC-06）。OpenAI API キー方式は切り替え先にせず、OpenAI API キー方式を選んでいるときは切り替えない（切り替え先を選ぶ設定がないため。理由は [アーキテクチャ](アーキテクチャ.md)「macOS のセッションの整形と入力履歴」）。切り替えて成功したときは HUD に知らせない（仮置き）。実機で未確認 | #199 / #58 |
| 処理中の再押下・Esc・認識モデルの削除 | 処理中にもう一度押したときの「キャンセルするか確認する」は、フォーカスを奪わないパネルで尋ねる（見た目・位置は仮置きで実機で未確認）。Esc でのキャンセルの設定は、Esc の捕捉が #51 の判定まで無効のため、今はオンにしても使えない。認識モデルの「削除」は公開 API の都合で予約の解除だけを行い、実際の削除は macOS に任せる（すぐには消えない） | #199 / #51 |
| ChatGPT での整形（OpenAI API キー方式） | 既定は無効（処理系は Local Basic）。設定画面の「整形の実行先と費用」タブで「ChatGPT（OpenAI API キー方式）」を選び、整形用モデル名を入力し、OpenAI API キー（クラウド音声認識と同じキー）を保存し、同意の画面で ChatGPT への整形の送信（Sign in with ChatGPT と同じ同意）に同意し、月次予算と単価表にそのモデルの単価を入れたときだけ、利用者の API キーで OpenAI へ送る（API の利用料がかかる）。モデル名の既定値・単価の初期値は持たない（候補は [Phase0検証-ChatGPT登録条件.md](Phase0検証-ChatGPT登録条件.md)「付記: OpenAI API キー方式の先行実装」の仮置き）。失敗したら Local Basic で整形し、Sign in with ChatGPT・Claude へは切り替えない（失敗時の切り替えの設定の対象外）。見込みの出力トークン（予約額の計算に使う `max_output_tokens`）と受信量・文字数の上限は仮置き。実機・実 API で未確認。この方式を足す前のビルドへ戻すと、送信先を Claude として読む（Claude への同意・API キー・予算がそろっていれば Claude へ送る）。戻したビルドで設定を保存すると、送信先は Claude で上書きされ、OpenAI の整形用モデル名は消える | #58 |
| Edit Mode | MVP 外の先行実装。既定でショートカットが未割り当てのため、設定画面の「録音とショートカット」タブで録音とは別のキーを割り当てて保存するまで使えない。送るには同意の画面の「選択テキストの編集」への同意（整形とは別）と、Claude API キー・月次予算・単価表が要る（ChatGPT へは送らない, #50）。Edit Mode の送信先は Claude だけで、整形の処理系に Sign in with ChatGPT を選んでいても ChatGPT へは送らない。選択範囲の取得と置き換えは AX を使うため、アプリごとの可否は挿入の検証の結果に左右され、実機で未確認。指示の長さの上限（60 秒）は仮置きで、指示の録音では STT Worker の異常終了後の認識のやり直しをしない | #60 / #41 |
| Realtime Direct | MVP 外の実験機能。設定画面の「録音とショートカット」タブの入力モードで明示的に選んだときだけ使う（既定は Instant）。対応を確かめたアプリ（`RealtimeDirectAllowlist.verified`）がまだないため、選んでもすべてのアプリで自動で無効になり、HUD で知らせて停止後にまとめて入力する。許可リストへの追加は実機で範囲追跡と取り消しを確かめてから行う（手順は [アーキテクチャ](アーキテクチャ.md)「Realtime Direct」。Debug ビルドでは起動引数 `-UtterRealtimeDirectDebugApps` で試すアプリを足せる）。使えるときも整形はしない。クラウド STT は一括認識のため使えない。STT Worker の異常終了後の認識のやり直しはしない。実機で未確認 | #60 / #41 |
| クラウド STT | MVP 外の先行実装で既定は無効。macOS だけで、設定画面の「認識モデルと省電力」タブで選び、同意の画面の「クラウド音声認識」への同意（整形とは別）・OpenAI API キー・月次予算と単価表（モデル `gpt-4o-mini-transcribe` の単価）がそろったときだけ録音音声を OpenAI へ送る。モデル名と1秒あたりの見込みの使用量は仮置きで、設定画面では変えられない。一括認識のため Realtime Preview の途中経過は出ない。失敗しても認識し直さず（ローカルのエンジンにも切り替えない）、起動時の復旧と Edit Mode の指示はローカルのエンジンで認識する。iOS は対象外。実機で未確認 | #60 / #188 |
| 自動更新（Sparkle） | appcast の URL と公開鍵をビルド設定で与えたときだけ動く。与えなければ Sparkle を起動しない | — |
| 公式バイナリ | Developer ID 署名・公証のワークフローはあるが、まだ配布していない。今は自前ビルドのみ | #47 / #59 |
| 速度・メモリ・電力 | 6章の目標は未計測。設定画面の保持モードは STT Worker に送るが、保持時間などの値は計測前の仮置きのまま | #52 / #59 |
