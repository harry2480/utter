# Phase 0 検証: WhisperKit のモデル選定・メモリ・安定性（#49）

## 目的

WhisperKit（オンデバイス STT）の以下を確定：
- 日本語対応モデルの選定（tiny, base, small, medium）
- メモリ使用量・推論速度の現実性確認
- 安定性・エラーレート測定

## テスト環境

- OS: macOS 14.0+、iOS 15.0+ 対象
- デバイス: MacBook Pro, iPhone 実機（複数機種）
- ネットワーク: オフライン環境（モデルロード完了後）

## 検証用コード

計測には [Verification/WhisperKitProbe](../Verification/WhisperKitProbe/README.md) を使う（モデル取得と初回ロード、推論時間・RTF、phys_footprint の推移、連続推論、`utter-eval` 用の STT 結果の出力）。
熱・電力は `powermetrics` を並行して記録する。手順・出力の見方・モデル重みのライセンスと取得元は同 README を参照。

## テスト項目

### 1. モデルサイズ比較

| モデル | パラメータ | ダウンロード | メモリ（推定） | 推論速度 |
|-------|----------|----------|----------|--------|
| tiny | 39M | ~42MB | ~200MB | < 1s |
| base | 74M | ~140MB | ~400MB | 1-2s |
| small | 244M | ~461MB | ~1GB | 2-5s |
| medium | 769M | ~1.5GB | ~2.5GB | 5-10s |

**推奨: base モデル**（精度・速度・メモリのバランス）

### 2. 実機メモリ計測

```
テスト手順:
1. モデルロード前の空きメモリ記録
2. モデルロード（warm-up 含む）
3. 認識タスク実行（5分音声）
4. ピークメモリ、平均メモリを記録

期待結果（base モデル）:
- ピークメモリ: < 1.5GB（iPhone 標準機種）
- 認識完了後のメモリ解放: ≥ 80%
```

### 3. 安定性テスト

```
テスト項目:
- 連続認識 10 回の成功率（≥ 98% 目標）
- エラーケース（嘆息、雑音、無音）の処理
- タイムアウト（5分超）の挙動確認

期待結果:
- クラッシュなし
- エラー時の graceful degradation
```

## 実装検討事項

- モデル初回取得時の UI 通知（ダウンロード進捗）
- キャッシュディレクトリの管理（重複ダウンロード防止）
- 古いモデルの自動削除ポリシー

## 検証結果の記録

### 2026-10-31：合成音声での精度・ロード・メモリ（macOS、Apple M5）

詳細は [docs/計測/2026-10-31-合成音声-STT比較.md](計測/2026-10-31-合成音声-STT比較.md)（SpeechAnalyzer と同じ音声で比較）。

| | base | small | large-v3 turbo（632MB） |
|---|---:|---:|---:|
| 取得サイズ | 142.7MB | 478.8MB | 623.6MB |
| 初回ロード | 8.5 秒 | 19.0 秒 | 132.2 秒 |
| 2回目以降のロード | 0.38 秒 | 0.45 秒 | 1.39 秒 |
| 実時間比（40件の合計） | 0.031 | 0.079 | 0.157 |
| 自プロセスのメモリの最大 | 87.8MB | 109.0MB | 113.0MB |
| CER 合計（日本語 / 開発用語） | 25.3%（6.7% / 49.0%） | 22.8%（1.8% / 45.7%） | 17.2%（0.0% / 25.0%） |

- 合成音声（`say -v Kyoko`）の 40件での参考値。人の声での精度は未計測
- メモリは目標（1GB 以下）に収まるが、Core ML のモデル分（GPU・ANE 側）を含まない可能性がある

### 2026-10-31：連続推論での安定性（large-v3 turbo、macOS、Apple M5）

詳細は [docs/計測/2026-10-31-WhisperKit連続推論.md](計測/2026-10-31-WhisperKit連続推論.md)。

- WhisperKitProbe 単体（`bench`）での計測。アプリに組み込んだ状態（XPC Worker 経由）での連続利用は未計測
- 126.7 秒の音声を約31分（270回）休まず推論し、270回とも成功、すべて1回目と同じ結果だった。推論時間は 6.83〜6.94 秒で、熱による遅れはなかった
- 熱状態は全区間 `nominal`、Mac 全体の熱の警告もなし。フリーズ・再起動・クラッシュもなかった
- 自プロセスのメモリは約320MB で頭打ちになり、増え続けなかった（目標 1GB 以下）
- 消費電力は `powermetrics` に管理者権限が要るため未計測
- モデル重みのライセンスと取得元は、[ライセンス・依存関係.md](ライセンス・依存関係.md) の2章と [WhisperKitProbe の README](../Verification/WhisperKitProbe/README.md) の「モデル重みのライセンスと取得元」に記録済み。2026-10-31 に、取得元 `argmaxinc/whisperkit-coreml` のコミット（`0f63a78`）とライセンス（MIT。トークナイザーは Apache-2.0）が変わっていないことを確かめた
