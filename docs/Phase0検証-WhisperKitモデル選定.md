# Phase 0 検証: WhisperKit のモデル選定・メモリ・安定性（#49）

## 目的

WhisperKit（オンデバイス STT）の以下を確定：
- 日本語対応モデルの選定（tiny, base, small, medium）
- メモリ使用量・推論速度の現実性確認
- 安定性・エラーレート測定

## テスト環境

- OS: macOS 14.0+、iOS 15.0+ 対象
- デバイス: MacBook Pro, iPhone 実機（複数機種）
- ネットワーク: オフライン環境（モデルロード完了後）

## テスト項目

### 1. モデルサイズ比較

| モデル | パラメータ | ダウンロード | メモリ（推定） | 推論速度 |
|-------|----------|----------|----------|--------|
| tiny | 39M | ~42MB | ~200MB | < 1s |
| base | 74M | ~140MB | ~400MB | 1-2s |
| small | 244M | ~461MB | ~1GB | 2-5s |
| medium | 769M | ~1.5GB | ~2.5GB | 5-10s |

**推奨: base モデル**（精度・速度・メモリのバランス）

### 2. 実機メモリ計測

```
テスト手順:
1. モデルロード前の空きメモリ記録
2. モデルロード（warm-up 含む）
3. 認識タスク実行（5分音声）
4. ピークメモリ、平均メモリを記録

期待結果（base モデル）:
- ピークメモリ: < 1.5GB（iPhone 標準機種）
- 認識完了後のメモリ解放: ≥ 80%
```

### 3. 安定性テスト

```
テスト項目:
- 連続認識 10 回の成功率（≥ 98% 目標）
- エラーケース（嘆息、雑音、無音）の処理
- タイムアウト（5分超）の挙動確認

期待結果:
- クラッシュなし
- エラー時の graceful degradation
```

## 実装検討事項

- モデル初回取得時の UI 通知（ダウンロード進捗）
- キャッシュディレクトリの管理（重複ダウンロード防止）
- 古いモデルの自動削除ポリシー
