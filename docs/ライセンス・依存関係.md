## モデル配布方式（Phase 0 決定待ち）

### 案 A: 同梱配布
- 初回起動時のダウンロード不要
- ビルドサイズ増大（WhisperKit small ≈ 1GB）
- 署名・公証の時間増加

### 案 B: 初回取得（推奨）
- ビルドサイズ削減
- ユーザーの初回体験時に取得
- 完全性検証：SHA-256 ハッシュ確認
- 取得元：Hugging Face（WhisperKit 公式）

## 署名・公証方式（Phase 0 決定待ち）

### macOS Developer ID Signing

- **Notarization**（Apple 公証）は長期配布に必須
- CI での自動署名・公証フロー構築予定（Phase 2）

### 自前ビルド

- Developer ID 署名は不要（ローカルテスト用）
- ビルド時に Ad Hoc 署名
